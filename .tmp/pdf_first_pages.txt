Streszczenie pracy dyplomowej w języku polskim
    Praca inżynierska skupia się na opracowaniu wieloplatformowego systemu do nauki
języków obcych. Ma on za zadanie wspomagać w procesie nauki poprzez
wykorzystywanie fiszek oraz funkcjonalności tłumaczenia słownictwa. We
wprowadzeniu przedstawiono cele i założenia systemu, problemy związane z nauką
języków obcych, takie jak krzywa zapominania czy brak motywacji, oraz
przeprowadzono przegląd istniejących rozwiązań, takich jak Duolingo, Memrise, Anki i
Quizlet, wskazując ich ograniczenia oraz propozycje usprawnień. System używa
zmodyfikowanego algorytmu SuperMemo 2, który określa, kiedy dane słówko ma zostać
powtórzone. Używa technologii takich jak React, Electron, SQLite, aplikacja również
pozwala na korzystanie w trybie offline, personalizację treści oraz wgląd do statystyk.
Praca obejmuje etapy projektowania, implementacji oraz testowania systemu.

Abstract of the thesis in English
    The engineering work focuses on the development of a multi-platform language
learning system. Its goal is to support the learning process using flashcards and
vocabulary translation functionality. The introduction presents the goals and objectives
of the system, language learning problems such as the forgetting curve and lack of
motivation, and reviews existing solutions such as Duolingo, Memrise, Anki and Quizlet,
pointing out their limitations and suggestions for improvement. The system uses a
modified SuperMemo 2 algorithm that determines when a word should be reviewed. The
project uses technologies such as React, Electron and SQLite. The application also allows
offline use, personalization of content and generation of statistics. The work includes the
design, implementation and testing stages of the system.

Spis skrótów i oznaczeń
   •   Frontend - część aplikacji widoczna dla użytkownika, z którą bezpośrednio
       wchodzi w interakcję.
   •   Backend - warstwa aplikacji odpowiedzialna za logikę biznesową, przetwarzanie
       danych i operacje w tle.
   •   Framework - zestaw narzędzi, bibliotek i zasad, dzięki którym tworzenie aplikacji
       w danym języku programowania jest łatwiejsze.
   •   Responsywność - zdolność strony internetowej               do   automatycznego
       dostosowywania się do różnych rozmiarów ekranów.
   •   XML (ang. Extensible Markup Language) - uniwersalny język znaczników
       zaprojektowany do przechowywania i transportu danych w ustrukturyzowanej
       formie. Umożliwia definiowanie niestandardowych tagów i struktur, co pozwala
       na łatwą wymianę danych między różnymi systemami.
   •   HTML (ang. HyperText Markup Language) - język znaczników służący do
       strukturyzacji i prezentacji treści na stronach internetowych. Definiuje elementy
       takie jak nagłówki, akapity, obrazy i linki, które są interpretowane przez
       przeglądarki internetowe.
   •   CSS (ang. Cascading Style Sheets) - język stylizacji, który pozwala na
       formatowanie wyglądu tych elementów, np. ich kolorów, rozmiarów czy układu
       na stronie.
   •   DOM (ang. Document Object Model) - hierarchiczna reprezentacja dokumentu
       HTML lub XML w postaci obiektów i węzłów, umożliwiająca dynamiczne
       manipulowanie treścią, strukturą oraz stylem strony internetowej.
   •   Stylowanie - proces definiowania właściwości elementów HTML na stronie
       internetowej za pomocą CSS, obejmujący zmiany wyglądu oraz zachowanie
       elementów HTML.
   •   Renderowanie - proces, w którym komponenty React przekształcają dane
       wejściowe na elementy wirtualnego DOM, a następnie synchronizują je z
       rzeczywistym DOM.
   •   Providery – w React to komponenty udostępniające dane lub funkcjonalności (np.
       globalny stan) dla innych komponentów w aplikacji.
   •   Routing – w React to mechanizm umożliwiający nawigację między różnymi
       widokami lub stronami aplikacji poprzez dynamiczne zmienianie adresu URL.
   •   Endpoint - punkt dostępu w aplikacji, który umożliwia komunikację między
       klientem a serwerem, zazwyczaj reprezentowany przez konkretny URL
       obsługujący określoną funkcjonalność.

List of Abbreviations and Terms
   •   Frontend - the part of the application visible to the user, with which they directly
       interact.
   •   Backend - the layer of the application responsible for business logic, data
       processing, and background operations.
   •   Framework - a set of tools, libraries, and rules that make creating applications in
       each programming language easier.
   •   Responsiveness - the ability of a website to automatically adapt to different screen
       sizes.
   •   XML (Extensible Markup Language) - a universal markup language designed for
       storing and transporting data in a structured form. It allows the definition of
       custom tags and structures, facilitating data exchange between different systems.
   •   HTML (HyperText Markup Language) - a markup language used for structuring
       and presenting content on websites. It defines elements such as headers,
       paragraphs, images, and links, which are interpreted by web browsers.
   •   CSS (Cascading Style Sheets) - a styling language that allows formatting the
       appearance of these elements, e.g., their colors, sizes, or layout on a page.
   •   DOM (Document Object Model) - a hierarchical representation of an HTML or
       XML document in the form of objects and nodes, enabling dynamic manipulation
       of content, structure, and styles of a web page.
   •   Styling - the process of defining the properties of HTML elements on a webpage
       using CSS, including changes to appearance and behavior of HTML elements.
   •   Rendering - the process by which React components transform input data into
       elements of the virtual DOM, which are then synchronized with the real DOM.
   •   Providers – in React, these are components that provide data or functionalities
       (e.g., global state) to other components within the application.
   •   Routing – in React, this is a mechanism that enables navigation between different
       views or pages of the application by dynamically changing the URL.
   •   Endpoint - an access point in an application that enables communication between
       a client and a server, typically represented by a specific URL handling a defined
       functionality.

1. Wstęp

1.1. Wprowadzenie
   System do nauki języków obcych to aplikacja edukacyjna, która została stworzona z
myślą o pomocy użytkownikowi w nauce języków obcych przy użyciu fiszek i tłumaczeń
słownictwa. Wykorzystuje zmodyfikowany algorytm powtórek interwałowych
SuperMemo 2, który dostosowuje częstotliwość powtórek do indywidualnych potrzeb
użytkownika. System używa technologii takich jak React, Electron i SQLite, dzięki
czemu aplikacja działa płynnie na różnych platformach, takich jak Windows, Linux i
macOS.


1.2. Cele i założenie
    Celem pracy jest skonstruowanie systemu umożliwiającego naukę języków obcych,
który zaoferuje użytkownikowi funkcjonalności w zakresie przyswajania słownictwa
oraz realizowania powtórek zaprojektowanych w sposób dynamicznie dopasowany do
indywidualnego poziomu trudności. Realizacja tego celu wymaga implementacji
interaktywnego interfejsu użytkownika, bazującego na bibliotece React, cechującej się
zdolnością do dynamicznego renderowania komponentów oraz zarządzania stanem
aplikacji.
    Na poziomie backendowym zostanie zastosowane środowisko Electron, oferujące
możliwość tworzenia wieloplatformowych aplikacji desktopowych, jednocześnie
pozwalając na integrację z Node.js. Ta integracja otwiera drogę do wykorzystania
zaawansowanych funkcjonalności, takich jak dostęp do systemu plików (Node File
System). Dane użytkownika, obejmujące między innymi słownictwo, talie czy postępy w
nauce, które są zapisane w lekkiej bazie danych SQLite. Jej struktura umożliwia lokalne
przechowywanie danych przy minimalnym wykorzystaniu zasobów dyskowych, co w
konsekwencji zapewnia mobilność tych danych, łatwość ich transferu pomiędzy
urządzeniami oraz możliwość modyfikacji kodu bazy w sposób dostępny dla
użytkownika.
    Kluczowym aspektem projektowanego rozwiązania jest funkcjonowanie systemu w
trybie offline, co eliminuje konieczność utrzymywania stałego połączenia z Internetem.
Aplikacja ma dostarczać narzędzia pozwalające na efektywną naukę w warunkach
ograniczonego dostępu do sieci, umożliwiając tym samym korzystanie z fiszek i
tłumaczeń w dowolnym momencie. Taki model działania przekłada się na zwiększoną
elastyczność użytkowania, odpowiadając na potrzeby użytkowników, niezależnie od
miejsca i okoliczności, w których się znajdują.

1.3. Przegląd zawartości pracy
    W rozdziale pierwszym, oprócz przedstawienia celów, założeń i wprowadzenia,
poruszone zostaną problemy związane z nauką języków obcych. Omówione zostaną
również wyzwania związane z nauką, takie jak motywacja.
    Rozdział drugi będzie się skupiał na opisie oraz zasadach działania algorytmu
SuperMemo 2. Zostanie przedstawiony wstęp do algorytmu, mechanizm oceny oraz
obliczanie odstępów między powtórkami. Na końcu zostaną przedstawione zalety i
ograniczenia algorytmu.
    Trzeci rozdział będzie opisywać założenia projektowe systemu oraz użyte
technologie. Przedstawiona zostanie również idea działania programu.
    Rozdział czwarty będzie skupiał się na implementacji i wdrożeniu systemu.
Omówione zostaną kluczowe elementy bazy danych, modyfikacja algorytmu
SuperMemo 2 oraz szczegółowy opis funkcjonalności poszczególnych stron.
    Rozdział piąty będzie skupiał się na testowaniu systemu.
    Na końcu pracy znajdą się wnioski i uwagi końcowe, które podsumują zrealizowane
cele, a także przedstawią sugestie dotyczące dalszego rozwoju i potencjalnych ulepszeń
systemu.


1.4. Problemy związane z nauką języków obcych
    Przy nauce języków obcych, rzeczą oczywistą może być, że im szybciej możliwe jest
przyswojenie nowego słownictwa, tym lepiej. Jednak rzeczywistość nie jest tak prosta.
Przykładowo osoba ucząca się może początkowo zapamiętać dużą liczbę słówek, jednak
z czasem pewna część tej wiedzy zostaje zapomniana. Jest to naturalna kolej rzeczy, to
zjawisko jest również znane jako krzywa zapomnienia, które wymaga, aby uczący
systematycznie się uczył, żeby przyswoić wiedzę [1]. Problemem jest to, że bez
odpowiednich narzędzi ciężko jest ustalić, kiedy najefektywniej należy powtarzać, co
może prowadzić do frustracji i utraty motywacji.
    Nauka języków obcych wymaga dostosowania metody do indywidualnych potrzeb
użytkownika. Każda osoba inaczej radzi sobie z nauką mając inne tempo nauki,
preferencje przyswajania wiedzy oraz różne poziomy zaawansowania w danym języku.
Z tego powodu systemy do nauki języków obcych muszą dostarczać spersonalizowane
treści dla każdej pojedynczej osoby, jednak jest to trudne do osiągnięcia zwłaszcza, kiedy
system posiada dużą liczbę użytkowników. Na przykład algorytm SuperMemo 2
optymalizuje powtórki na podstawie statystycznego modelu zapominania [2], co w
większości przypadków działa dobrze, jednak nie zawsze uwzględnia wyjątkowe
potrzeby poszczególnych osób.

dużej ilości pracy, wytrwałości oraz regularności. System nie potrafiący zachęcić
